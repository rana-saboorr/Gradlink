# Gradlink 🌐

**Gradlink** is a full-stack web application for international education consulting — helping students find universities, visa guidance, and career counseling worldwide.

> 📂 The main application lives in the [`Gradlink/`](./Gradlink) subdirectory.

---

## Quick Start

```bash
cd Gradlink
cp .env.example .env   # Fill in your Firebase credentials
npm install
npm run dev            # → http://localhost:5173/
```

---

## Tech Stack

- **React 19** + **Vite 8** + **React Router v7**
- **Firebase** (Firestore + Storage)
- **Redux Toolkit** for state management
- **Tailwind CSS v4** + Framer Motion
- **React Hook Form** + Zod
