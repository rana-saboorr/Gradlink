## ✨ Key Features

### 🏠 Dynamic Homepage

- 📢 Live Announcements fetched directly from **Supabase**
- 💼 Dynamic Services section
- ✨ Modern Glassmorphism UI
- 📱 Fully Responsive Design
- ⚡ Optimized for high performance

---

### 🔐 Admin Portal

Complete management dashboard featuring:

- 👥 Team Member Management (CRUD)
- 📢 Announcement Management (CRUD)
- 🛠️ Services Management (CRUD)
- 💼 Job Posting Management (CRUD)
- ⚙️ Admin Account Settings
- 🔑 Change Username, Email & Password
- 🔒 Protected Admin Routes
- 💾 Persistent Login Sessions

---

### 📁 Smart File Uploads

- Upload Team Member profile images
- Stored securely in **Supabase Storage**
- 2MB upload validation
- Real-time preview
- Automatic storage handling

---

### 💼 Careers Page

- Live job openings
- Dynamic data from Supabase
- Instant updates without redeployment

---

### 🎨 Modern UI

- 🌙 Dark Mode
- ☀️ Light Mode
- Glassmorphism Design
- Tailwind CSS v4
- Responsive Layout
- Smooth Framer Motion animations

## 🔒 Security & Data Integrity

✔️ Row Level Security (RLS) enabled across all database tables

✔️ SQL Injection protection through Supabase ORM parameterized queries

✔️ Secure Admin Authentication

✔️ Protected Routes with Redux Toolkit

✔️ Persistent Sessions using sessionStorage

✔️ Environment variables isolated via `.env`

✔️ Secure image uploads with validation
